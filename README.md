## Description

cub3D is a graphical project that explores the foundations of 3D rendering through the implementation of a Raycasting engine. Inspired by the world-famous 1992 game Wolfenstein 3D, this project involves creating a first-person perspective environment within a maze-like structure, built entirely in C using a minimalist graphics library (MinilibX).

The core objective is to master mathematical concepts like trigonometry and geometry to project a 2D map into a 3D visual representation in real-time.

## Instructions

### Execution

Execute the following command in your terminal at the project root:

``make``

This will generate the cub3D executable.

The program requires a single argument: a path to a scene description file with the .cub extension.

``./cub3D maps/example.cub``

### Controls

Once the game is running, you can navigate the maze using the following keys :

#### Key	Action
> W / S	Move forward / backward

> A / D	Strafe left / right

> Left / Right Arrows	Rotate the camera

> Mouse	Rotate the camera (Bonus feature)

> ESC	Exit the game cleanly
